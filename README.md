Cờ Caro AI (Minimax & Alpha-Beta Pruning)

Dự án này là một phiên bản trò chơi cờ Caro (Gomoku thu nhỏ) hoạt động trên giao diện dòng lệnh của Python. Người chơi sẽ đối đầu với Trí tuệ nhân tạo (AI) trên bàn cờ kích thước 9x9. 

Luật chơi: Người chơi (X) và AI (O) luân phiên đánh. Bên nào tạo được một đường liên tiếp **4 quân** (ngang, dọc, hoặc chéo) trước sẽ giành chiến thắng.

---

## 🛠 Yêu Cầu Hệ Thống

* Python 3.6 trở lên.
* Thư viện `numpy` (để quản lý ma trận bàn cờ).

---

Hướng Dẫn Cài Đặt và Chạy Chương Trình

Bước 1: Cài đặt thư viện
Mở Terminal (hoặc Command Prompt) tại thư mục chứa mã nguồn dự án và chạy lệnh sau để cài đặt các thư viện cần thiết:
pip install -r requirements.txt
Bước 2: Khởi chạy trò chơi
Sau khi cài đặt xong, khởi chạy chương trình bằng lệnh ( tên file code của bạn là main.py):
ấn run (ctrl + 5)
